## API Endpoints Summary

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/auth/steam/login` | GET | Start Steam OpenID flow |
| `/api/auth/steam/callback` | GET | Handle Steam OpenID return |
| `/api/auth/steam/connect` | POST | Manual Steam ID connection |
| `/api/auth/steam/disconnect` | POST | Disconnect Steam account |
| `/api/steam/owned-games` | GET | Get user's Steam game library |
| `/api/steam/sync-games` | POST | Sync Steam library manually |
| `/api/steam/common-games` | POST | Find common games between users |

## Common Issues & Solutions

### Issue: "Steam not connected" error
**Solution**: Check that `is_steam_connected` is set to `True` in database after connection

### Issue: No games showing in library
**Solution**: Check that games are properly associated in `user_games` table after sync

### Issue: Steam API errors
**Solution**: Verify `STEAM_API_KEY` is valid and not rate limited

### Issue: Callback URL not working
**Solution**: Ensure `APP_BASE_URL` and `FRONTEND_URL` match your actual Codespace URLs

## Database Schema Check

Ensure these tables exist with proper relationships:
- `user` table has Steam fields (steam_id, steam_username, etc.)
- `steam_game` table exists 
- `user_games` association table links users to games
